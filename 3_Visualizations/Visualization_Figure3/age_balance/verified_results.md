# Age-balance verification

Across five calipers (0.1–0.9 years), 332–378 participants per severity range were matched, reducing the absolute between-range age standardized mean difference (SMD) from 0.759 to 0.0005–0.057, whereas the unmatched subsets showed greater age imbalance (absolute SMD = 2.807–5.020).

SMD uses subset-specific sample variances (ddof=1). All five matching ID sets reproduce the saved results. These are descriptive statistics; no inferential confidence intervals or significance tests are shown.
