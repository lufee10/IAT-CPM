Cross-range generalization loss under a common pooled-model residualized evaluation target. Histograms show 5,000 paired participant bootstrap resamples for lower-to-higher severity (target n=461) and higher-to-lower severity (target n=653). Loss is the target group's within-range OOF correlation minus the source model's cross-range correlation, both computed against the same pooled-model fold-specific residualized IAT. Frequency denotes bootstrap resamples per bin; both directions use identical bin edges. Shaded bands indicate the 95% percentile interval; the red vertical line marks the observed difference. These are bootstrap sampling distributions, not permutation null distributions. Intervals condition on fixed predictions and do not include retraining uncertainty. This pooled-target comparison is distinct from source-referenced evaluation and uses observed IAT to define ranges.
